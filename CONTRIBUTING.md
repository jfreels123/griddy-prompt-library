# Contributing

Keep additions practical.

## Standards

- Add prompts that solve a real spreadsheet task
- Tie prompts to a dataset when possible
- Write expected results so someone can verify the output
- Prefer clear business language over vague prompt-engineering jargon
- Do not add filler prompts just to increase file count

## Prompt template

Each prompt file should include:

- a short task title
- one-paragraph description
- exact prompt text
- sample data reference
- expected result
- related Griddy page links

## Dataset guidelines

- Use small CSVs that are easy to inspect
- Avoid private or proprietary data
- Use realistic column names and values
- Keep sample files simple enough for quick demos
