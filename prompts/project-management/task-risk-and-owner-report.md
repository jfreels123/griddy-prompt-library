# Task Risk And Owner Report

Find the work most likely to slip.

## Prompt

```text
Review this task tracker, flag anything overdue or unassigned, calculate days remaining to deadline, and build a short report showing the highest-risk tasks by owner.
```

## Sample data

- `../../../datasets/project-management/tasks.csv`

## Expected result

- Flags overdue tasks
- Flags unassigned tasks
- Calculates days remaining
- Produces a risk summary by owner
