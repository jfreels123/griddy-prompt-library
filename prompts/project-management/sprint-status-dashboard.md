# Sprint Status Dashboard

Build a quick sprint view from a task board export.

## Prompt

```text
Turn this sprint board into a dashboard that shows tasks by status, points completed versus remaining, blocked work, and the tasks due in the next three days.
```

## Sample data

- `../../../datasets/project-management/sprint-board.csv`

## Expected result

- Summarizes work by status
- Totals completed and remaining points
- Highlights blocked work
- Flags near-term due items
