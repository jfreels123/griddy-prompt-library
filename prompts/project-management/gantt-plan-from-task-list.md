# Gantt Plan From Task List

Turn a plain task list into a timeline view.

## Prompt

```text
Create a simple Gantt-style timeline from this task list using start date, due date, owner, and status. Color-code tasks by status and group them by project phase.
```

## Sample data

- `../../../datasets/project-management/tasks.csv`

## Expected result

- Creates a timeline-oriented view
- Groups tasks by phase
- Uses status-based color coding
- Makes schedule overlap easy to scan
