# Meal Plan And Grocery List

Turn a meal plan into a cleaner weekly prep sheet.

## Prompt

```text
Organize this meal plan by day, combine duplicate grocery items, total quantities where possible, and create a separate grocery list sorted by section like produce, protein, pantry, and dairy.
```

## Sample data

- `../../../datasets/personal/meal-plan.csv`

## Expected result

- Structures meals by day
- Consolidates duplicate ingredients
- Produces a cleaner grocery list
- Sorts items into shopping sections
