# UTM Cleanup And Channel Rollup

Clean messy campaign tracking data and make it usable.

## Prompt

```text
Clean this traffic export by standardizing source, medium, and campaign names, then build a rollup showing sessions, signups, and signup rate by channel.
```

## Sample data

- `../../../datasets/marketing/traffic-export.csv`

## Expected result

- Normalizes inconsistent UTM labels
- Builds a cleaner channel summary
- Calculates signup rate
- Makes performance comparisons easier
