# Follow-Up Priority Board

Surface the leads and deals that need attention first.

## Prompt

```text
Prioritize this sales list by urgency. Flag anything with no touch in the last 14 days, highlight overdue follow-ups, and create a short board that groups records into Hot, Due Soon, and At Risk.
```

## Sample data

- `../../../datasets/sales/pipeline.csv`

## Expected result

- Calculates days since last touch
- Flags overdue next steps
- Groups records into simple priority buckets
- Produces a follow-up view that can be used in a weekly sales review
