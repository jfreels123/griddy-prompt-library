# Lead Source Conversion Summary

See which lead sources actually produce revenue.

## Prompt

```text
Summarize this lead table by source. Show total leads, qualified leads, opportunities, customers, and conversion rates for each source, then sort the sources by customer conversion rate.
```

## Sample data

- `../../../datasets/sales/leads.csv`

## Expected result

- Groups leads by source
- Calculates conversion steps through the funnel
- Sorts sources by final conversion rate
- Surfaces low-quality and high-quality channels
