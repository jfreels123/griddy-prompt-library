# Stalled Deal Review

Find the deals that need intervention now.

## Prompt

```text
Review this pipeline and identify stalled deals. Flag anything that has not moved stages in more than 21 days or has an overdue next step, then create a manager summary grouped by owner.
```

## Sample data

- `../../../datasets/sales/pipeline.csv`

## Expected result

- Flags stalled or neglected deals
- Creates a manager-ready summary by owner
- Highlights overdue next steps
- Helps focus the next pipeline review
