# Prompt Guide

Each prompt file follows the same structure:

- what the task is
- the exact prompt
- the sample data file to use
- the expected result
- one or two related Griddy pages

When adding new prompts:

- prefer specific business tasks over generic spreadsheet chores
- keep prompts short enough to paste directly into the product
- tie prompts to a realistic table with named columns
- avoid filler prompts that exist only to inflate repo size
