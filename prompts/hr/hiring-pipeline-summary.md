# Hiring Pipeline Summary

Summarize recruiting activity by stage and role.

## Prompt

```text
Summarize this hiring pipeline by role and stage. Show how many candidates are in each stage, flag candidates stuck for more than 10 days, and create a recruiter summary by owner.
```

## Sample data

- `../../../datasets/hr/candidates.csv`

## Expected result

- Counts candidates by stage
- Flags stalled candidates
- Produces a recruiter summary
- Makes bottlenecks visible by role
