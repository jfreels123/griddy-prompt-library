# Expense Cleanup And Categorization

Clean a messy expense log and organize it for reporting.

## Prompt

```text
Clean this expense log by trimming extra spaces, standardizing the date format, converting amounts to numbers, and assigning a category to each merchant based on the description. Then create a summary table showing total spend by category.
```

## Sample data

- `../../../datasets/finance/expense-log.csv`

## Expected result

- Fixes inconsistent dates
- Converts text amounts into numeric values
- Normalizes merchant names
- Assigns useful expense categories
- Produces a category summary table
