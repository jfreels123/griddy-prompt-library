# Budget Variance Analysis

Compare budgeted and actual spend, calculate variance, and highlight problem categories.

## Prompt

```text
Compare actual spend to budget for each category, add variance in dollars and percent, highlight categories that are more than 10% over budget in red, and add a summary chart showing budget vs actual by category.
```

## Sample data

- `../../../datasets/finance/budget-vs-actual.csv`

## Expected result

- Adds dollar variance and percent variance columns
- Formats percent variance cleanly
- Highlights categories that exceed budget by more than 10%
- Builds a chart comparing budget vs actual
